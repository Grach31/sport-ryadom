# Спорт рядом — Хостинский район, Сочи

Карта спортивных площадок района. Данные площадок — из реестра (`data/places.json`), фото — `photos/`.
Контур района, берег, дороги и реки берутся из OpenStreetMap, координаты адресов — через Nominatim.
Карту собирает GitHub Actions (`build-map`, запускается при изменении данных или вручную: Actions → build-map → Run workflow) и сохраняет в `data/map.json`.

Если какая-то площадка стоит не на своём месте, добавь её координаты в `data/coords_override.json`:
`{"12": [43.5521, 39.8123]}` (id площадки: [широта, долгота]) и запусти сборку ещё раз.
